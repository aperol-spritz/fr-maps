# Asset and source notes

The original map files and their visible author notices are preserved:

- `assets/neverwinter.webp`: the existing base map of the project.
- `assets/evernight.jpg`: the user-supplied Evernight image, unchanged.
- `assets/parchment.png`: existing interface decoration.
- `assets/underground-pending.svg`: a neutral placeholder, not a geographic map.

The lore consists of the project's brief RU/UA summaries with article links and
source dates retained in the generated journals. See [lore sources](https://github.com/aperol-spritz/fr-maps/blob/main/docs/content-1492.md).
Neither the build nor release automation changes source attribution or grants
redistribution rights. The uncertain sewer reference and local audit captures
are excluded from the installable package. Package registration/publication
remains a maintainer action.
