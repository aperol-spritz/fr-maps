# Neverwinter: City Map 0.19.0

## Atlas interface and fixes

- Add a second parchment design and a palette menu with previews, selection
  indicators, keyboard navigation and persistent per-client choice. Both designs
  keep the same frame and map geometry.
- Add a 1.8-second parchment reveal without scaling the real map or text. Closing
  or interacting ends it cleanly; reduced-motion preferences skip the animation.
- Group the location list by subject with RU/UA alphabetical ordering, while
  preserving categories, document identities and permissions.
- Frame the complete location card, make its title open the journal, and open
  the exact location page on double-click in the list.
- Fix repeatedly reopening a journal after raising the native atlas window:
  invalidate Foundry's stale active-window marker before the next bringToFront.
- Add bulk view/owner/hide controls for all location markers and distinguish
  partial player access. Territories and character markers retain their own
  access, and campaign-authored text is preserved.

## Journals and resources

- Expand from 60 to 66 locations: Scar Keep, Deekin Street, Coriol Street, Tymor
  Street, Skull Fortress and Vilebog. Include updated Beggar's Nest references.
- Supply two developed RU/UA paragraphs for each location, with related links
  and source references in a smaller footer. Keep research/reconstruction notes
  in editorial records instead of rendered player articles.
- Preserve existing location/journal/page IDs and original page order; the two
  journals now contain 132 pages. All six animated location GIFs remain unchanged.
- Bundle the new `parchment-aged.png`; the reference animation used during design
  is not a runtime dependency.
- Keep collection `neverwinter-atlas.city` stable. The manifest's new directory
  `packs/city-prose-20261115` avoids rewriting the former installed database.

## Verification

Portable release tests use disposable Git repositories and local mock HTTP
services. Automated ZIP/UI scenarios run in separate empty worlds on Foundry
14.370; the Atlas matrix supports dnd5e 6.1.0 and 6.0.6 using separate system
copies. Final results and exact artifact hashes are recorded under `docs/testing/`.
Historical reports verify their own snapshots and are not treated as final
release evidence. Existing campaigns, installed packs and the Foundry listing
are not modified by this release procedure.
