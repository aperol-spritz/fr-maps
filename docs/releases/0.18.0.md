# Neverwinter: City Map 0.18.0

- Bundle the six user-uploaded animated location GIFs with portable paths, both
  in the RU/UA journals and as default atlas pin images.
- Include the prepared lore expansion: 60 locations, 120 bilingual journal
  pages, ten added location summaries and their historical/source context.
- Capture authored coordinates for House of Knowledge, Bluelake, Neverwinter
  River, Moonstone Mask and the Chasm rift, plus pin styling and ruler calibration.
- Preserve current territory geometry and label settings, and existing world
  overrides. Retain the newer source lore and expanded relationships rather than
  replacing them with stale legacy world overlays. Incorporate the Castle Never
  public description's direction to the Hall of Justice.
- Include canonical location metadata and authored map defaults in the city
  compendium. The atlas reads bundled defaults directly; no startup journal
  import is required.
- Add reproducible local ZIP packaging, compiled-pack/media/link validation,
  and an automated disposable Foundry ZIP installation scenario.

The collection remains `neverwinter-atlas.city`; existing journal/page IDs and
the pack directory `packs/city-v17` remain stable. Compatibility remains Foundry
14, verified 14.370. Source campaigns, user grants and legacy backup journals
are not modified or distributed. Publication uses the existing GitHub-only
workflow; Foundry directory submission remains disabled.
