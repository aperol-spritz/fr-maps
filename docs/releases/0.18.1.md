# Neverwinter: City Map 0.18.1

## Fixes and interface changes

- Disable inherited CSS transitions during character dragging, so the marker
  tracks pointer movement without interpolation lag.
- Await journal sheet rendering and call `bringToFront()` when opening a
  location journal, including from the location title.
- Add character search across permitted characters; the initial list shows up
  to three alphabetically sorted characters assigned to online players.
- Add a vertical sidebar toggle, cog controls and an adjacent colored access
  indicator. Scale the pin access badge with the pin's size.
- Remove visible period/precision filters and editorial caveats from player
  cards and newly compiled journals. Retain source metadata and development
  notes separately.
- Include expanded RU/UA journal prose for the six animated-image locations.

## Content and verification scope

The city collection remains `neverwinter-atlas.city`: two journals, 120 pages,
six unchanged animated GIFs and 392 internal links. Existing journal/page IDs,
map positions, territories and world overrides remain stable. The ZIP includes
the updated runtime files as well as freshly compiled journals.

Portable checks cover canonical rows, archive contents, media bytes/paths and
release recovery against local mocks. The disposable Foundry 14.370 ZIP scenario
covers journal opening/reload, both languages, GIF loading, character search,
pointer-step drag tracking and the sidebar toggle. Broader coverage of three
simultaneously online characters, access badges at multiple zoom levels and
intermittent window stacking remains pending; this release does not claim that
those cases have all been reproduced and resolved.

Compatibility remains minimum Foundry 14, verified 14.370. No source campaign
or installed compendium is rebuilt. Publication uses the GitHub-only workflow.
