# Проверка лорных статей для игроков

Результат: PASS. Node 24.22.1, Foundry 14.370, dnd5e 6.1.0.

- `node-tests.txt`: 41/41 переносимых теста; release-сценарии используют
  одноразовые Git-репозитории и mock HTTP, без публикаций.
- `foundry.json`: полный автоматический ZIP/journal/UI-сценарий в одноразовом
  мире; все 132 страницы сравниваются с каноническим текстом, 450 внутренних
  ссылок разрешаются, анимации загружаются, повторное открытие после
  перезагрузки проходит. Проверены отдельные клиенты ведущего и игроков.
- `ru-lake.png` и `uk-lake.png`: реальные окна журнала в Foundry. Основной
  текст 15 px, примечания 12 px. Примечания следуют после лора и содержат
  обогащённую внутреннюю ссылку и внешнюю ссылку на источник.
- Публичный читатель замка содержит историческую справку без реконструкций
  и даты разработки. Остальные сценарии навигации, доступа и оформления
  сохранены и выполнены.

Сборка и `npm run verify` прошли. Установленный локально
`packs/city-prose-20261115` создан новым каталогом из проверенной сборки с
побайтовым сравнением каждого файла. Старый каталог не открывался и не
перестраивался. После смены пути выполнены новая сборка и верификация;
браузерный отчёт относится к предыдущему тестовому ZIP с тем же содержимым
пака и прежним путём в манифесте.

Исходный игровой мир и импортированные в него журналы не изменялись.
Личная оценка литературного качества в автоматическую проверку не входит.
Повторная сверка всех первоисточников и отдельный прогон на dnd5e 6.0.6
в этот этап не входили. Исторические отчёты сохранены.
