# Меню оформления и одинаковые размеры — 2026-11-15

Исправление по замечаниям пользователя:

- Палитра между шестерёнкой и RU открывает меню, а не меняет дизайн сама.
- В меню два варианта с образцами и галочкой у выбранного.
- Выбор сохраняется как прежде в клиентской настройке `design`.
- Escape и щелчок снаружи закрывают меню. Клавиши Enter/Space открывают меню
  и выбирают вариант, стрелки/Home/End перемещают фокус между вариантами.
- У обоих дизайнов одинаковые отступы 20 px и отображаемая рамка 26 px.
  Для нового пергамента используется масштабируемая рамка с заполнением
  середины, как у классического. Отличается только изображение и размер
  исходного фрагмента текстуры; PNG не перерисовывался.
