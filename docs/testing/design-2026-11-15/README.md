## Подготовка изображения

Использован встроенный редактор изображений с прозрачным фоном. Финальный запрос:

> Use case: background-extraction. Edit target: attached wide landscape aged
> parchment sheet. Remove only the exterior white background and make it
> genuinely fully transparent. Preserve the entire irregular burnt/torn paper
> silhouette, brown edge, interior aged beige texture, stains, creases and
> landscape proportions. No cropping of the paper, no new objects, no text,
> no white halo or checkerboard. This is a UI parchment background texture.
> Return a transparent PNG suitable for a resizable interface.
