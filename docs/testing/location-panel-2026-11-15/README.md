# Карточки, доступ и справки на 1492 год

Проверка: 15 ноября 2026 года, Node 24.22.1, Foundry 14.370, dnd5e 6.1.0.
Используется новый локальный ZIP, отдельный временный каталог Foundry и
независимые клиенты ведущего, разрешённого и исключённого игроков.
Установленная база `city-v17` и игровой мир не перестраиваются.

## Изменения

- Общая рамка карточки охватывает название, справку, связанные места, район,
  шестерёнку и глазик. Список остальных мест расположен ниже.
- Заголовок выделен собственной рамкой; наведение и клавиатурный фокус
  подсвечивают кнопку открытия журнала.
- Двойной щелчок по строке списка открывает именно её страницу; одинарный
  щелчок выбирает локацию. ПКМ по пустой карте снимает выбор.
- ПКМ по глазику меняет общий просмотр, владение и запрет, сохраняя
  индивидуальные исключения. Двойной щелчок открывает отдельную форму доступа.
- Цвет учитывает всех игроков мира: зелёный — все видят, синий — все владеют,
  жёлтый — видит только часть, красный перечёркнутый — никто не видит.
- Шестерёнка редактирует публичный текст и оформление без прав доступа.
- Публичный читатель включает расширенную справку и реконструкцию; отзыв
  доступа убирает значок, карточку и открытое окно читателя.

## Проверка

Итог: полный ZIP/journal/UI suite прошёл 63 проверки; `npm test` — 37/37.
`npm run build` и `npm run verify` прошли. В архиве два журнала, 132 страницы.
Итоговый архив: `build/local-DfMYxN/module.zip`. Состояние runtime и источника
справок сверено с проверенным архивом. Результаты сохранены в
`foundry-report.json`, `node-tests.txt`, `verification.txt` рядом с этим файлом.

`tests/location-panel.mjs` проверяет реальные жесты и независимые клиентские
сессии внутри полного `tests/journals.mjs`. Он сохраняет и восстанавливает
исходное тестовое состояние. Сценарий также проверяет недоступность глазика
игроку, наличие исключения после быстрого переключения и оба глазика —
на метке и в карточке. `selected-card.png` — снимок выбранного замка с жёлтым
индикатором частичного доступа.

`tests/node/location-access.test.mjs` проверяет наследование, смешанные права,
цикл разрешений, запрет действий игрока и сохранение авторских текстов при
дополнении отсутствующих абзацев. `tests/node/lore.test.mjs` проверяет умеренный
объём обеих языковых версий, явную маркировку реконструкций, отсутствие событий
после 1492 и компиляцию каждого абзаца в соответствующую языковую страницу.

Отдельные старые сценарии `access`, `rich-map`, `layers-position`, `move-undo`
и `territory-presentation` сохранены и переведены на отдельную форму глазика.
Полный запуск этих отдельных исторических сценариев в данный прогон не входит;
актуальная проверка изменённых жестов выполнена в полном ZIP/journal/UI suite.

## Локальная установка

Для журналов используется новая папка `packs/city-1492-20261115`; старый
`packs/city-v17` сохраняется. ID коллекции и страниц не меняются. Публикация
релиза, тега и записи Foundry не выполнялась. Работающему серверу нужен
перезапуск для чтения нового пути компендиума, затем обновление браузеров.
Первое открытие атласа ведущим дополняет недостающие публичные абзацы в записях
карты, сохраняя существующие тексты кампании, права и геометрию.
